# Fraud Detection Platform

## Description

Plateforme de détection de fraude bancaire en temps réel.

## Technologies

- Python
- FastAPI
- Apache Kafka
- Apache Spark Structured Streaming
- PostgreSQL
- XGBoost
- Docker
- Redis

## Statut

Projet en cours de développement.

## Configuration

Définissez la variable d’environnement `DB_PASSWORD` avec le mot de passe de
votre base PostgreSQL avant de lancer les services backend. Ne publiez pas de
fichier `.env` ni de véritable mot de passe.
